# pythonAdvanced

This repository contains my learning notes, code examples, and hands-on exercises from an Advanced Python course. The goal is to strengthen my Python programming skills by exploring advanced concepts, best practices, and real-world applications.

## Folder Structure

- **ASYNC/** - Asynchronous programming with async/await, concurrency patterns, and event loops
- **DECORATORS/** - Function and class decorators, custom decorators, and decorator patterns
- **INHERITANCE/** - Object-oriented inheritance including single inheritance, multi-level inheritance, and multiple inheritance
- **OOPS/** - Object-Oriented Programming fundamentals: classes, constructors, encapsulation, and methods
- **POLYMORPHISM/** - Polymorphic behavior, method overriding, and duck typing
- **PYDANTIC/** - Data validation and serialization using Pydantic library (basics and advanced topics)
